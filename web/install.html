Installation

Get SKgate CLI up and running in minutes

check_circle Prerequisites

  • • Python 3.10+ - Download here
  • • pip - Usually comes with Python
  • • Git (optional) - For cloning repository
computer

Windows

1 Clone Repository
git clone https://github.com/coffe-skelet/Sqgateway.git cd Sqgateway
2 Run Installer
.\install.bat
3 Restart Terminal

Close and reopen PowerShell/CMD

4 Verify
sqz --version
download Download install.bat
terminal

Linux / macOS

1 Clone Repository
git clone https://github.com/coffe-skelet/Sqgateway.git cd Sqgateway
2 Run Installer
chmod +x install.sh ./install.sh
3 Reload Shell
source ~/.bashrc # or ~/.zshrc
4 Verify
sqz --version
download Download install.sh

rocket_launch Quick Setup After Installation

# Initialize configuration sqz install # Add your Gemini API key sqz keys add mykey YOUR_GEMINI_API_KEY # Start gateway sqz start --daemon # Try chat sqz chat

Troubleshooting

Problem: "sqz: command not found"

Solution:

  • • Restart your terminal/PowerShell
  • • Check if Python Scripts is in PATH
  • • Try: python -m sqz_cli.main --version

Problem: "pyproject.toml not found"

Solution:

  • • Make sure you're in the Sqgateway directory
  • • Run: cd path/to/Sqgateway
  • • Verify: ls pyproject.toml (Linux/macOS) or dir pyproject.toml (Windows)
