Инфраструктура, а не ещё одна обёртка над чатом.

Squeeze Gateway — прозрачный прокси между приложением и LLM-провайдером. Он не меняет формат API и не требует переписывать клиент: достаточно заменить базовый URL. Всё, что он делает, измеряется и записывается в журнал.

Как это работает Проверить вживую

Задача

problem

Большая часть счёта за LLM — это не ответы модели, а служебная обвязка: вежливые формулировки, дублирующиеся инструкции, избыточные внутренние рассуждения на простых вопросах. Пользователь платит за токены, которые не влияют на результат.

Промпты содержат 20–40 % «воды», которую можно снять без потери смысла.
Модель тратит сотни thinking-токенов там, где хватило бы короткого ответа.
Существующие «оптимизаторы» часто показывают красивые цифры без методики.

Принцип

honest metrics

Любая экономия считается как разница между тем, что запрос стоил бы без шлюза, и тем, что он стоил фактически. Baseline берётся у самого провайдера через countTokens, а не оценивается эвристикой. 

// так считается каждая запись журнала
saved = baseline
      - actual_input
      - aux_tokens        // расход самого шлюза
      - thinking_saved    // через thinkingLevel
Если служебный расход выше экономии, в журнале будет отрицательный результат. Мы его не скрываем.

Что оказалось сложным

Реальные ограничения, а не список галочек

Кириллица в C++

regex

std::regex с \b и icase не работает для UTF-8: границы слов определены только для ASCII. Русские паттерны пришлось заменить на детерминированные подстроки и явные правила регистра. Заодно MSVC потребовал /utf-8 — без него строковые литералы превращаются в мусор.

Честный baseline

countTokens

Сравнивать «до и после» на глаз бессмысленно: токенизатор зависит от модели. Поэтому baseline запрашивается у провайдера отдельным вызовом. Это стоит немного латентности, но даёт цифру, которую можно проверить снаружи.

Экономия, которая убыточна

aux

LLM-сжатие короткого промпта сняло 22 токена, но сам компрессор потратил 333. Итог — минус. Поэтому включён порог 2000 символов и отдельный учёт aux_tokens: механизм, который не окупается, должен отключаться сам.

Квоты и перегрузка

503 / 429

Бесплатный тариф Gemini — около 20 генераций в день на модель. Шлюз ретраит только перегрузку (503) с паузами 1/2/4 с, а на 429 сразу отдаёт понятную ошибку: ретраи в этом случае лишь сжигают остаток квоты.

Адрес шлюза

localStorage

На GitHub Pages нет серверной части, поэтому страницы обращаются к шлюзу по адресу, который вы укажете здесь. Адрес хранится только в вашем браузере. Запустите шлюз локально: 

uvicorn server:app --port 8082
