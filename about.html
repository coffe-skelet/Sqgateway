Making AI More Efficient

The Story

Squeeze Gateway started as a school project in 2026 to address a simple problem: LLM costs were growing faster than application budgets. Most optimization tools were either black boxes with unverifiable claims, or required significant code rewrites.

We built Squeeze Gateway to be different: a transparent proxy that requires zero code changes — just replace the API endpoint. Every optimization is measured against an honest baseline (the provider's own token counter), and all metrics are logged locally.

The C++ core was added when we realized that simple heuristics (removing politeness, deduplication) could save 5-36% on verbose prompts at near-zero cost. The thinking controller came from observing that simple queries waste tokens on unnecessary reasoning depth.

Today, Squeeze Gateway processes real traffic with measured 30-60% token savings on mixed workloads, all while maintaining response quality and providing complete observability.

Core Values

Measure, Don't Estimate

Every claim is backed by reproducible measurements. We use the provider's own token counter as baseline, not our own guesses.

Do No Harm

Compression defaults are conservative. On dense technical prompts, the C++ core barely touches anything — preserving quality beats saving tokens.

Zero Lock-In

Standard API format, open-source code, local deployment. You control your data, infrastructure, and provider choice.

Privacy First

All metrics stored locally. No external analytics, no prompt logging, no telemetry to third parties. Your data never leaves your infrastructure.
